# Creditos

## Desenvolvimento

- Codigo, design de fases e integracao no Godot: Felipe Anjos.

## Motor e ferramentas

- [Godot Engine](https://godotengine.org/) 4.6 (licenca MIT).
- GitHub Actions para integracao continua e publicacao de releases.

## Arte

- Todos os elementos visuais (espelhos, obstaculos, cristal, feixe de luz,
  cenario) sao desenhados via codigo (`_draw()` em GDScript), sem uso de
  imagens externas. O icone do projeto (`icon.svg`) e o icone padrao gerado
  pelo Godot.

## Audio

- `assets/audio/menu_loop.mp3` (musica do menu), `assets/audio/gameplay_music.mp3`
  (musica das fases) e `assets/audio/prisma_ambient.wav` (ambiente do
  prototipo original).

> fonte, o autor e a licenca de uso de cada uma antes da publicacao final.
